# Lab 1 - IUM

## Temat sprawozdania: Środowisko pracy inżyniera uczenia maszynowego
Celem ćwiczenia jest stworzenie odpowiedniej konfiguracji dla środowiska programistycznego, które pozwoli na odpowiedni przebieg pracy nad modelami uczenia maszynowego. Instrukcja laboratoryjna ma na celu zapoznanie studentów z systemem kontroli wersji git oraz korzystania z wirtualnego środowiska venv w IDE do zagwarantowania spójnego ekosystemu deweloperskiego.
